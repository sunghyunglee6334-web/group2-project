# Class Labeling Guide

## 공통 원칙

- 사용 Class: 0~6 (번호는 `configs/classes.yaml` 과 같아야 하며 바꾸지 않습니다)
- 판단이 명확한 객체만 해당 Class 로 지정합니다.
- Class 판단이 어려우면 임의로 결정하지 않고 **REVIEW** 로 보내고, Issue 칸에 사유를 적습니다.
- 김치 자체는 검출 대상 Class 가 아닙니다. 정상 김치는 Class 가 아니라 Scene Type(`normal_kimchi`) 입니다.
- Class 4 고무장갑은 현재 프로젝트에서 사용하지 않습니다.

---

## Class 0 — 나뭇잎·종이류

### 대상
조각김치 사이에서 발견되는 나뭇잎 또는 종이 형태의 객체

### 포함
- 나뭇잎, 잘린 잎 조각
- 종이 조각

### 제외
- 김치(배추) 잎
- 파, 고추

### 애매한 경우
- 나뭇잎인지 김치 잎인지 명확하지 않으면 REVIEW (`class_ambiguous`)

---

## Class 1 — 플라스틱·돌·금속

### 대상
플라스틱, 돌, 금속처럼 제조 과정에서 들어간 이물

### 포함
- 플라스틱 조각, 비닐 조각
- 돌, 모래 덩어리
- 금속 조각

### 제외
- 나뭇가지, 식물성 잎
- 파·고추

### 애매한 경우
- 재질을 이미지로 판단하기 어려우면 REVIEW

---

## Class 2 — 나뭇가지류

### 대상
막대 또는 가지 형태의 나무성 이물

### 포함
- 나뭇가지, 작은 가지 조각
- 줄기 형태의 목질 이물

### 제외
- 파 줄기, 고추 꼭지
- 일반 잎 조각

### 애매한 경우
- 나뭇가지와 채소 줄기의 구분이 어려우면 REVIEW

---

## Class 3 — 벌레류

### 대상
이미지에서 확인되는 벌레 또는 곤충 형태의 객체

### 포함
- 벌레, 곤충 형태가 명확한 객체

### 제외
- 작은 검은 반점, 양념 덩어리
- 형태를 식별할 수 없는 이물

### 애매한 경우
- 벌레인지 단순 얼룩인지 판단하기 어려우면 REVIEW (`too_small_to_identify`)

---

## Class 4 — 고무장갑

### 현재 사용 여부
사용하지 않음 (`configs/classes.yaml` 에서 `enabled: false`)

### 처리 기준
- 새 BBox 를 Class 4 로 만들 수 없습니다 (프로그램이 막음).
- 기존 TXT 에서 Class 4 가 발견되면 **삭제하지 않고 REVIEW** 로 저장합니다 (프로그램이 자동으로 REVIEW 로 바꿈).
- PM + QA 가 실제 객체를 보고 다른 Class 로 바꿀지, 그대로 둘지 판정하고 Note 에 근거를 남깁니다.

---

## Class 5 — 병해·갈변

### 대상
식재료에서 확인되는 병해 또는 갈변 형태

### 포함
- 갈색으로 변색된 부위
- 병해로 판단되는 이상 부위

### 제외
- 정상적인 김치 양념 색
- 그림자, 촬영 조명에 의한 색 변화

### 애매한 경우
- 실제 갈변인지 조명 차이인지 판단하기 어려우면 REVIEW

---

## Class 6 — 파·고추

### 대상
조각김치 이미지에서 검출 대상으로 지정된 파 또는 고추

### 포함
- 파 조각
- 고추 조각

### 제외
- 김치 잎, 나뭇잎
- 나뭇가지

### 애매한 경우
- 파·고추와 다른 식물 조각을 구분하기 어려우면 REVIEW

---

## REVIEW 사유 코드 (Issue 칸에 그대로 적기)

| 코드 | 뜻 |
|---|---|
| `class_ambiguous` | 어느 Class 인지 판단이 어려움 |
| `class4_found` | 사용하지 않는 Class 4 발견 |
| `not_target_maybe` | 검출 대상인지 자체가 불확실 |
| `too_small_to_identify` | 너무 작아 식별 불가 |

## 팀 예시 (Pilot 30장에서 합의 후 추가)

| 상황 | 결정 | 근거 |
|---|---|---|
| (예: 갈색 막대 모양, 가지인지 파 줄기인지 애매) | (REVIEW → Class 2 확정) | (단면에 나뭇결이 보임) |
