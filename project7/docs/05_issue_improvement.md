## 1. 프로그램

### ISSUE-01 WSL 메뉴 잔상 · 클릭 오류
- **문제**: 메뉴를 옮겨 열면 이전 드롭다운이 화면에 남고, 마우스를 빨리 움직이면 색이 남고, 옆 메뉴를 바로 누르면 닫힘
- **원인**: WSLg 가 Tkinter 기본 메뉴(별도 창)를 다시 그리지 않음 · `<Leave>` 이벤트 누락
- **개선**: 메뉴를 메인 창 안의 Frame 으로 직접 구현 (`src/ui/menubar.py`) · 첫 바깥 클릭은 메뉴 닫기에만 사용
- **결과**: DEV-01 ~ 04 재시험 PASS ([02 Test Report](../reports/02_test_report.md) 0장)

### ISSUE-02 단축키 · 화면 버그
- **문제**: Caps Lock 이면 Ctrl+S 안 됨 · 필터 결과 0장이면 이전 사진 정보가 남음 · 깨진 이미지에 이전 박스가 겹침 · `--raw` 실행 때 WORK 폴더 이름이 달라짐
- **개선**: 대 · 소문자 모두 연결 · 빈 화면 초기화 · 불러오기 실패 시 편집 불가 표시 · WORK 이름을 `work_<RAW폴더>` 로 통일
- **결과**: DEV-05 ~ 08 재시험 PASS

### ISSUE-03 쓰기 불편함 6건 (팀 QA)
- **문제**: 화면 이동 후 커서 복귀 안 됨 · 좌우 키만 이동 · 이슈 · 노트 한글 입력 불가 · 필터가 섞여 있음 · 상태 아이콘이 헷갈림 · 이름 입력 불편
- **개선**: 그리기 · 박스 편집 · 이동 버튼 + Esc 복귀 · 방향키 4개 · 내장 한글 입력기 · 탭 재정리 · 상태를 한글 + 아이콘으로 · 이름 선택창
- **결과**: 디자인 v02 배포 (목록 → 작업 → 정보 순서) — [docs/images/gui_v01.png](images/gui_v01.png) → [gui_v02.png](images/gui_v02.png)

### ISSUE-04 장부 출처 · 폴더 중복
- **문제**: `manifest.csv` 경로에 학습데이터 1 · 2 출처가 없음 · 작업 폴더 안에 `labels` 폴더가 겹쳐 생김
- **개선**: 출처 경로 표기 · 폴더 생성 수정 · Class 개수 열 추가
- **결과**: v2.1 (PR #10) · v2.2 (PR #11) 배포

## 2. 기준서

### ISSUE-05 고무장갑 Class
- **문제**: 원본 라벨에 고무장갑이 Class 1 · 4 로 섞여 있었고, 팀 기준도 Class 1 + REVIEW → Class 4 사이에서 바뀜
- **원인**: 고무장갑은 '이물' 이 아니라 공정 배경인데 기준서에 정해져 있지 않았음
- **개선**: Class 기준서 v1.7 — 고무장갑 = 배경, 박스를 그리지 않고 기존 박스는 삭제 → EDITED · Class 4 번호는 비워 둠 (교과 8 dataset.yaml 과 번호 맞춤)
- **결과**: Class 1 박스 1,831 → 1,665 (−166) 정리에 포함

### ISSUE-06 작은 이물
- **문제**: 작은 스티로폼 알갱이를 '어차피 학습에서 안 잡힌다' 고 빼려 함
- **원인**: 라벨을 빼면 모델이 그 이물을 **배경으로 배움** · 교과 8 에서 해상도 비교 실험도 불가능해짐
- **개선**: Class 기준서 v1.6 — 작아도 확실하면 박스 + 노트 `small` · 3px 규칙
- **결과**: 기존 검수 520장 다시 확인

## 3. 데이터 · QA

### ISSUE-07 QA Summary 보정 숫자 0건 ★
- **문제**: QA Summary 를 만들었더니 '그대로 유지' 만 있고 수정 · 추가 · 삭제가 전부 0
- **원인**: 프로그램 버그가 아님 — 비교 기준(RAW) 자리에 **이미 고친 폴더**가 들어가 '고친 것 vs 고친 것' 을 비교함 (GUI 의 폴더 열기가 설정의 RAW 경로를 바꿈)
- **개선**: 원본(`--raw`)과 합친 작업본(`--work`)을 직접 지정해서 다시 생성
- **결과**: 정식 숫자 유지 2,016 · 위치 · 크기 2,014 · Class 25 · 추가 350 · 삭제 344 → [01 QA Summary](../reports/01_qa_summary.md) (PR #36)

### ISSUE-08 배경만 있는 사진 2장
- **문제**: 자동 검사 '빈 라벨' 26건 중 2건이 장면 유형 '이물만' 인데 박스가 0개
- **원인**: 김치도 이물도 없이 **고무장갑만** 있는 사진 → 고무장갑 박스를 지우니 박스 0 · 기존 장면 유형 4개로는 분류 불가
- **개선**: 장면 유형 `none` (김치 · 대상 객체 없음) 추가 · Class 기준서 v1.7.2
- **결과**: 장면 유형 이물만 151 → 149 + none 2 (PR #37) · 빈 TXT 26 = 정상 김치 24 + none 2

### ISSUE-09 빈 폴더 검사 '통과' 표시
- **문제**: 사진이 0장인 폴더를 Validation 해도 '통과' 로 보이고, TXT 를 못 읽어도 조용히 넘어감
- **개선**: 검사 수행 범위(검사 · 생략 · 대상 없음) 표시 · 빈 폴더 = CRITICAL · TXT 읽기 실패 기록
- **결과**: PR #31 (QA) · 자동 테스트 4개 통과

### ISSUE-10 장부 CSV 형식 깨짐
- **문제**: 장부를 고쳐 올린 CSV 에서 쉼표가 `\,` 로 저장되어 49줄의 칸 수가 22 → 23 ~ 27 로 밀림
- **원인**: 따옴표 없이 쉼표를 이스케이프하는 방식으로 저장
- **개선**: 원래 장부에서 바뀐 2줄 4칸만 고친 정상본으로 교체 (BOM · 22칸 유지)
- **결과**: PR #37 Merge — 901줄 모두 22칸 확인
